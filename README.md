# Java Numero de Amstrong

## ✅Overview

The goal of this project is to develop a program that determines if a number is an Amstrong number. An Amstrong number is a number that is equal to the sum of its digits each raised to the power of the number of digits in the number.

## ✅Example

For example, the number 371 is an Amstrong number because it has three digits, and:
371 = 3^3 + 7^3 + 1^3 = 27 + 343 + 1 = 371
In this case, the sum of the digits raised to the power of the number of digits is equal to the original number, confirming that 371 is indeed an Amstrong number.

## ✅Test Cases:

The following test cases should be used to validate the program:

#### Positive test cases:
371 (Should return true, as it is an Amstrong number)
1634 (Should return true, as it is an Amstrong number)

#### Negative test cases:
351 (Should return false, as it is not an Amstrong number)
2015 (Should return false, as it is not an Amstrong number)
